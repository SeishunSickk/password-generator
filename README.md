# パスワード生成 Web アプリ

セキュリティに配慮したランダムなパスワードを即座に生成・コピーできる Web アプリケーションです。  
直感的な UI で文字種や長さを自由にカスタマイズできます。

## 🚀 アプリ URL
https://password-generator-b2yywz2avpmhapxvypdrg2.streamlit.app/

## 🛠️ 使用技術（技術スタック）
- **Language**: Python 3.x
- **Framework**: Streamlit
- **Security**: `secrets` モジュール（暗号学的に安全な乱数生成）
- **Deployment**: GitHub / Streamlit Community Cloud

- ## ✨ 主な機能
- **パスワード長の設定**: 4〜32 文字までスライダーで直感的に調整可能
- **文字種の個別に切り替え**: 英小文字・英大文字・数字・記号の選択（チェックボックス）
- **クリップボードコピー機能**: ボタン一つで生成されたパスワードをコピー
- **エラーハンドリング**: 全ての文字種チェックが外れた際に、アプリがクラッシュせず適切な警告を表示

- こだわりポイント
- **暗号学的に安全な乱数生成**: 標準の `random` モジュールではなく、セキュリティ耐性の高い `secrets` モジュールを採用。
- **UX（操作性）の考慮**: 
  - チェックボックスを 2 列レイアウト（`st.columns`）にして視認性を向上。
  - 生成されたパスワードには `st.code` を使用し、固定幅フォント（Monospace）で似た文字（`1` と `l` など）の誤認を防止。
- **例外処理（バリデーション）**: ユーザーが使える文字種を zero に設定した場合でもクラッシュせず、`st.error` で親切なエラーメッセージを表示。


## 💡 開発背景・動機（なぜ作ったか）
過去に複数のサービスでパスワードを使い回していた結果、**リスト型アカウントハッキング（リスト型攻撃）の被害に遭うという苦い経験**をしました。

この失敗から「サービスごとに異なる複雑なパスワードを安全に生成し、日常的に使い分ける重要性」を痛感し、自分自身や同じようなリスクを抱える人が**直感的に安全なパスワードを発行・利用できるツール**を目指して開発しました。
